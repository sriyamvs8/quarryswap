# Developer / Submission Checklist

1. `npm install`
2. `npm run build`
3. `npm run dev`
4. Test on a narrow mobile viewport.
5. Open Critical demo → req-1 → inspect green/yellow/red candidates.
6. Open req-2 to demonstrate pressure failure (350 bar requirement vs 250 bar stock).
7. Open req-3 to demonstrate bearing dimension/application edge cases.
8. Start a handoff and move it through the Active Loans page.
9. Reset demo before recording final walkthrough.
10. Deploy to Vercel/Netlify and test the public URL in an incognito window.
11. Push repository with `.env` excluded.
12. Submit public prototype URL + public repo URL + `TRADEOFFS.md`.
